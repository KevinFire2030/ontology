# ontology

ontology 프로젝트 저장소입니다.

## 현재 상태

프로젝트 초기 설정 단계입니다. 기능과 기술 스택은 추후 정의합니다.

## 시작하기

```bash
git clone https://github.com/KevinFire2030/ontology.git
cd ontology
```

아직 실행할 애플리케이션이나 설치할 의존성은 없습니다.

## 구성

- `README.md`: 프로젝트 소개 및 시작 안내
- [온톨로지 따라하기](온톨로지%20따라하기/README.md): 이창근 저자의 WikiDocs 공개 웹판 보관본. 공개 목차 60개 페이지, 원본 HTML, 오프라인 열람용 HTML 및 이미지 포함.
