03. 실습 환경 준비

이 책의 모든 실습은 PostgreSQL 하나로 진행합니다. 벡터 검색에는 pgvector 확장을, 그래프 비교에는 재귀 CTE와 Apache AGE를 쓰기 때문에 새 데이터베이스를 따로 배울 필요가 없습니다. 이 장에서는 Python 패키지로 내장 PostgreSQL을 띄우거나(기본 경로) Docker Compose로 컨테이너를 띄운 뒤(선택 경로), Python 환경과 LLM API를 설정하고, 예제 코드 저장소의 구조와 평가 도구 사용법을 익힙니다. 평가 도구는 이후 모든 장에서 "같은 질문을 다른 구성으로 풀었을 때 무엇이 달라지는가"를 재는 저울 역할을 합니다.

이 장에서 다루는 내용

  • 03-1. PostgreSQL + pgvector 설치 (Docker Compose)
  • 03-2. Python 환경과 LLM API 설정
  • 03-3. 예제 코드 저장소 구조와 실행 방법
  • 03-4. 평가 도구: 같은 질문 세트로 여러 구성을 채점하는 방법
